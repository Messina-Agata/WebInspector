# WebInspector

<div style="display: flex; align-items: center;">
  <img src="WebInspectorIcon.png" width="150" style="margin-right: 15px;">
  <p style="margin: 0;">
    <strong>WebInspector</strong> is an app which allows developers and tech enthusiasts to analyze the DOM, inspect console logs, and monitor network traffic of any URL directly from their mobile devices, mimicking desktop browser Developer Tools.
  </p>
</div>

**Elements Tab**:
- Displays the full HTML DOM tree.
  
<img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/010dc10a-5484-48c0-b216-94539eb997dd" />


**Console Tab**:
- Monitors JavaScript logs and errors.

<img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/e8d9926e-1072-4824-b57a-5ccd43b79e8b" />


**Network Monitor**:
- Live stream of network requests with real-time text filtering.

<img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/f23458f3-1ebd-4172-a646-d29aafb481cd" />
<img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/12dbcd1b-6bff-4188-973c-7cddf081a6a4" />

- Detailed drill-down for each request featuring:

    - **Headers**: View and copy request/response headers.

      <img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/8f680466-dff8-4737-aa7f-488633f61d5d" />

    - **Payload**: Inspect query parameters and POST bodies.

      <img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/d7bd2a10-560e-4ff7-b5bb-22077e9866d8" />

    - **Response**: Full response body viewer with text selection, copy, and search capabilities.

      <img width="348" height="754" alt="image" src="https://github.com/user-attachments/assets/64a5dea8-c6c0-4e8e-8d76-f8af7da59d6f" />
