PRIVACY POLICY – WebInspector
1. General information

This Privacy Policy describes how the mobile application WebInspector uses users' data.
The application is developed by Agata Messina. For reports or requests related to the application, use the official repository:
https://github.com/Messina-Agata/WebInspector.
The application is designed to work without collecting personal data and transferring any information to external servers.

2. Collected data

The application does not collect, save nor share any user personal data.
In particular:
- no names
- no e-mails
- no device ID
- no positions
- no sensitive data
- no data sent to external servers

3. Internet Access

The application requires Internet access to inspect web pages.
The application:
- does not send personal data
- does not track the user
- does not use its own cookies or profiling systems (any cookies enabled are strictly required by the websites visited by the user for their standard technical operations)

4. Third-party services

The application does not use:
- analysis services (Google Analytics, Firebase Analytics, etc.)
- advertising services (AdMob, Meta Ads, etc.)
- tracking services
- third-party SDKs which collects data

5. Data sharing

The application does not share any data with third-parties.

6. User's rights (GDPR)

Since the application does not collect personal data, there are no data to:
- access
- edit
- delete
- export
