## 📖 Features

**Elements Tab**:
- Displays the full HTML DOM tree.
screenshot

**Console Tab**:
- Monitors JavaScript logs and errors.
- Expandable entries for detailed log inspection.
screenshot

**Network Monitor**:
- Live stream of network requests with real-time text filtering.
- Long-press to instantly copy any request URL.
- Detailed drill-down for each request featuring:
    - **Headers**: View and copy request/response headers.
    - **Payload**: Inspect query parameters and POST bodies.
    - **Response**: Full response body viewer with text selection, copy, and search capabilities.
